# 🧮 Calculadora Premium

Calculadora científica com visual moderno e efeito Glassmorphism.

## Recursos

- Interface transparente
- Foto personalizada de fundo
- Operações básicas
- Porcentagem
- Memória MC / MR / M+ / M-
- Calculadora científica
- Raiz quadrada
- Sen, Cos e Tan
- Log e Ln
- Potência
- Pi
- Responsiva para Android e computador
- Pode ser instalada como PWA

## Como usar

Coloque sua imagem na mesma pasta dos arquivos.

Nome da imagem:

fundo.jpg

Depois abra o `index.html`.

## GitHub Pages

Envie os arquivos para um repositório do GitHub.

Depois vá em:

Settings → Pages

Selecione:

Deploy from a branch

Branch:

main

Folder:

/root

Salve e aguarde a publicação.
